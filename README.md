# MyPlugin

A PowerToys Run plugin.

## About

First plugin tryout for PowerToys Run.

**Activation keyword:** `wgu`

## Building

Requires:
- .NET 9.0 SDK
- Windows (WPF dependency)

```powershell
dotnet build
```

## Testing

```powershell
dotnet test
```
